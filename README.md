## 👋 About Me

I'm **Sabbir Ahmed**, a product-minded builder who enjoys working at the intersection of **technology, product thinking, AI, and real-world problem solving**.

I like taking ideas from:

`Problem → Idea → Prototype → Product`

rather than simply writing code for the sake of writing code.

Currently exploring and building around:

* 🚀 Product development
